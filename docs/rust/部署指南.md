## 系统要求

### 最低要求

- **操作系统**: Linux (Ubuntu 20.04+, Debian 11+, CentOS 8+), macOS 11+, Windows 10+ (WSL2)
- **CPU**: 2 核心
- **内存**: 2 GB RAM
- **存储**: 5 GB 可用空间
- **Rust**: 1.75 或更高版本
- **Node.js**: 22+ (用于 TypeScript 插件兼容)

### 推荐配置

- **CPU**: 4+ 核心
- **内存**: 4+ GB RAM
- **存储**: 10+ GB SSD
- **网络**: 稳定的互联网连接

## 安装 Rust 工具链

### Linux / macOS

```bash
# 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 配置当前 shell 环境
source "$HOME/.cargo/env"

# 验证安装
rustc --version
cargo --version
```

### Windows (WSL2 推荐)

```bash
# 在 WSL2 Ubuntu 中运行
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
```

### 安装附加工具

```bash
# 安装格式化和检查工具
rustup component add rustfmt clippy
```

## 构建项目

### 克隆仓库

```bash
git clone https://github.com/openclaw/openclaw.git
cd openclaw
```

### 安装依赖并构建

```bash
# 调试构建（开发用）
cargo build

# 发布构建（生产用，优化性能）
cargo build --release

# 构建时间约 1-2 分钟
```

### 构建输出

- **调试版本**: `target/debug/openclaw` (~10 MB)
- **发布版本**: `target/release/openclaw` (~1.6 MB, 已优化)

```bash

  },

    "api_key": null
  },
  "channels": {
    "whatsapp": false,
    "telegram": false,
    "discord": false,
```

### 环境变量

```bash
# 添加到 ~/.bashrc 或 ~/.zshrc
export OPENCLAW_CONFIG_PATH="$HOME/.openclaw/config.json"
export OPENCLAW_LOG_LEVEL="info"  # debug, info, warn, error
export OPENCLAW_DATA_DIR="$HOME/.openclaw/data"
```

## 运行服务

### 启动网关服务器

```bash
# 使用发布版本（推荐）
./target/release/openclaw gateway --host 127.0.0.1 --port 18789 --verbose

# 后台运行
nohup ./target/release/openclaw gateway --host 127.0.0.1 --port 18789 > gateway.log 2>&1 &

# 检查服务状态
curl http://127.0.0.1:18789/health
```

### 发送消息

```bash
./target/release/openclaw message \
  --message "你好，OpenClaw！" \
  --to "+8613800138000"
```

### 运行 AI 代理

```bash
./target/release/openclaw agent \
  --message "请生成一个任务清单" \
  --thinking high
```

### 查看版本信息

```bash
./target/release/openclaw version
```

## TypeScript 插件兼容性

OpenClaw Rust 实现通过 FFI (Foreign Function Interface) 桥接层保持与 TypeScript 插件的兼容性。

### FFI 桥接架构

```
TypeScript 插件
      ↓
  Node.js NAPI
      ↓
  openclaw-ffi (Rust)
      ↓
  openclaw-core (Rust)
```

### 安装 FFI 绑定

```bash
# 构建 Node.js 原生模块
cd crates/openclaw-ffi
npm install
npm run build

# 安装到项目根目录
npm install ./crates/openclaw-ffi
```

### TypeScript 插件示例

```typescript
// 导入 Rust FFI 绑定
import { init, createMessage, loadConfig } from '@openclaw/ffi';

// 初始化
init();

// 创建消息
const message = createMessage('session-id-here', 'Hello from TypeScript!');
console.log('Message ID:', message.id);

// 加载配置
const config = loadConfig();
console.log('Gateway:', config.gateway_host, ':', config.gateway_port);
```

### 现有插件兼容性

所有现有的 TypeScript 插件将继续工作：

- **channels**: WhatsApp, Telegram, Discord, Slack, Signal 等
- **extensions**: BlueBubbles, Matrix, Teams, Zalo 等
- **自定义插件**: 通过 plugin-sdk 开发的插件

## 生产环境部署

### 使用 systemd (Linux)

创建服务文件 `/etc/systemd/system/openclaw.service`:

```ini
[Unit]
Description=OpenClaw Gateway Service
After=network.target

[Service]
Type=simple
User=openclaw
Group=openclaw
WorkingDirectory=/opt/openclaw
ExecStart=/opt/openclaw/target/release/openclaw gateway --host 0.0.0.0 --port 18789
Restart=on-failure
RestartSec=5s

# 安全设置
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/var/lib/openclaw

# 资源限制
LimitNOFILE=65536
MemoryMax=2G

# 环境变量
Environment="OPENCLAW_CONFIG_PATH=/etc/openclaw/config.json"
Environment="OPENCLAW_LOG_LEVEL=info"
Environment="RUST_LOG=openclaw=info"

[Install]
WantedBy=multi-user.target
```

启用并启动服务：

```bash
# 重新加载 systemd
sudo systemctl daemon-reload

# 启用开机自启
sudo systemctl enable openclaw

# 启动服务
sudo systemctl start openclaw

# 检查状态
sudo systemctl status openclaw

# 查看日志
sudo journalctl -u openclaw -f
```

### 使用 Docker

创建 `Dockerfile.rust`:

```dockerfile
FROM rust:1.75-slim as builder

WORKDIR /app
COPY . .

# 构建发布版本
RUN cargo build --release

# 运行时镜像
FROM debian:bookworm-slim

# 安装运行时依赖
RUN apt-get update && \
    apt-get install -y ca-certificates && \
    rm -rf /var/lib/apt/lists/*

# 复制二进制文件
COPY --from=builder /app/target/release/openclaw /usr/local/bin/

# 创建数据目录
RUN mkdir -p /data
VOLUME /data

# 暴露端口
EXPOSE 18789

# 运行服务
CMD ["openclaw", "gateway", "--host", "0.0.0.0", "--port", "18789"]
```

构建和运行：

```bash
# 构建镜像
docker build -f Dockerfile.rust -t openclaw-rust:latest .

# 运行容器
docker run -d \
  --name openclaw \
  -p 18789:18789 \
  -v /opt/openclaw/data:/data \
  -e OPENCLAW_LOG_LEVEL=info \
  openclaw-rust:latest

# 查看日志
docker logs -f openclaw
```

### 使用 Docker Compose

创建 `docker-compose.rust.yml`:

```yaml
version: '3.8'

services:
  openclaw:
    build:
      context: .
      dockerfile: Dockerfile.rust
    ports:
      - "18789:18789"
    volumes:
      - openclaw-data:/data
      - ./config.json:/etc/openclaw/config.json:ro
    environment:
      - OPENCLAW_CONFIG_PATH=/etc/openclaw/config.json
      - OPENCLAW_LOG_LEVEL=info
      - RUST_LOG=openclaw=info
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:18789/health"]
      interval: 30s
      timeout: 10s
      retries: 3

volumes:
  openclaw-data:
```

运行：

```bash
docker-compose -f docker-compose.rust.yml up -d
```

## 监控与日志

```bash

./target/release/openclaw gateway --verbose 2>&1 | jq
```

## 故障排除

### 常见问题

#### 1. 端口已被占用

```bash
# 错误: Address already in use
# 解决方案：检查占用端口的进程
sudo lsof -i :18789
sudo kill -9 <PID>

# 或使用其他端口
./target/release/openclaw gateway --port 18790
```

#### 2. 权限错误

```bash
# 错误: Permission denied
# 解决方案：添加可执行权限
chmod +x target/release/openclaw

# 或使用 sudo（不推荐用于生产）
sudo ./target/release/openclaw gateway
```

#### 3. 依赖缺失

```bash
# 错误: error while loading shared libraries
# 解决方案：安装系统依赖
# Ubuntu/Debian
sudo apt-get install build-essential pkg-config libssl-dev

# CentOS/RHEL
sudo yum groupinstall "Development Tools"
sudo yum install openssl-devel
```
